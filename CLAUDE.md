# CCProject

Portfolio of browser-based game projects and SaaS applications.

## Projects

| Project | Path | Description |
|---|---|---|
| Flappy Bird | `flappy-bird/` | Arcade clone built with HTML5 Canvas. Single `index.html`, no dependencies. |
| FinHire | `finhire/` | AI-powered niche job board for AI-in-finance roles. Next.js 14 + TypeScript + Tailwind + Supabase. See `finhire/CLAUDE.md` for details. |

## Conventions

- One project per folder.
- Games are vanilla JS in a single `index.html` unless a build step is clearly needed.
- SaaS apps have their own `CLAUDE.md` in their project directory.
- Open any game by opening its `index.html` in a browser, or use a local server.
- SaaS apps: see project-level `CLAUDE.md` for build commands and architecture.
